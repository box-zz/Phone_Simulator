# 光岛 · Phone Simulator

刻舟求剑的我们，离不开的光岛。

一个纯前端虚拟手机制作器。打开 `index.html` 即可开始制作，也可以在项目目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

可分别创建、切换多个手机项目，编辑外观和应用内容，并导出从锁屏开始体验的独立手机网页。制作器预览按 393 × 852 的手机画布等比显示。

## 本地项目与 GitHub

GitHub 中保存的是制作器源码。创建的虚拟手机项目、聊天、上传照片和音频保存在当前浏览器的 IndexedDB 中，不会因为提交或推送源码而上传。浏览器数据与访问地址有关；切换浏览器、端口或地址可能看不到原来的项目。

要保留自己制作的内容，请使用「导出可编辑备份 JSON」，将备份保存到仓库外。手机体验 ZIP 用于单独分享作品，也应保存在仓库外。仓库已忽略常见导出包、备份文件及 `exports/`、`backups/`、`test-data/`、`screenshots/` 和 `assets-private/` 目录。

**不要用导出的手机体验 `index.html` 覆盖仓库根目录的 `index.html`。** 体验文件会嵌入具体项目内容；根目录应始终保留制作器源码。提交前检查 `git status` 和暂存区，确认没有作品素材、个人备份或测试数据。

## 分享作品

在制作器内查看「导出教程」，导出当前手机体验 ZIP，然后按教程上传静态网页。导出作品包含作者配置的内容，与 GitHub 上的制作器源码分开管理。访客的体验操作不会修改作者项目。
